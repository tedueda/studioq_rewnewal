使い方

1. ブラウザで直接生成する場合:

  1. テーマ、ターゲット、文字数を入力
  2. 画像を4枚アップロード
  3. OpenAI APIキーを入力
  4. 「ブログ記事を生成する」をクリック
  5. 生成されたJSONをダウンロード
  6. ダウンロードしたJSONとアップロードした画像を blog/blog-automation/ に配置
  7. node blog-auto-generator.js generate blog-data.json を実行

2. GitHub Actionsで自動生成する場合:

  1. テーマ、ターゲット、文字数を入力してキューに追加
  2. 画像を blog/images/ にコミット
  3. blog/blog-automation/blog-queue.json にキューデータをコミット
  4. GitHub Actionsが2日ごとに自動実行、またはActionsページから手動実行

3. 手動ワークフロー実行:

  1. GitHubリポジトリの「Actions」タブへ移動
  2. 「Blog Auto Generator」ワークフローを選択
  3. 「Run workflow」をクリックし、テーマ・ターゲット・文字数を入力して実行
